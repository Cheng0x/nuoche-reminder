# 车辆挪车提醒 — UI 设计

> 对应实现：`public/index.html` + `public/styles.css` + `public/app.js`

## 1. 设计原则

- **移动优先**：以 375px 视口为基准，最大内容宽度 480px 居中，桌面浏览呈卡片式。
- **一眼可达**：核心信息（挡路抱歉、车辆信息）在首屏无滚动即可看到。
- **克制配色**：中性底色 + 两个强调色（赤霞红、绿牌绿），避免花哨。
- **触控友好**：按钮最小高度 ≥ 44px，点击态明确。

## 3. 排版

| 角色 | 字号/字重 | 用途 |
|------|-----------|------|
| 页面标题 | 20px / 700 | 车辆名 |
| 挡路抱歉 | 40px / 800（letter-spacing 加宽） | 首屏核心 |
| 车牌字符 | 28px / 800（等宽感） | 绿牌 |
| 区块标题 | 15px / 700 | 分区说明 |

## 4. 组件设计

### 4.1 车辆信息卡（Vehicle Card）

- 白色圆角卡片，含浅灰分区。
- 结构：
  - 顶部品牌行：`小米 SU7 Pro` 加粗 + 右侧「赤霞红」色块标签（底色 `--accent-red`，白字圆角）。
  - 车牌区居中：新能源绿牌（见 4.2）。

### 4.2 新能源绿牌（CN NEV Plate）

- 外形：圆角矩形（约 220×56px），白描边 2px，绿渐变背景（`linear-gradient(135deg, var(--plate-green-1), var(--plate-green-2))`）。
- 字符：黑字、粗体；`鲁`（省份）+ 圆点分隔符（`·`）+ `CDN0940`。
- 省份与分隔符之间、分隔符与后 7 位之间留白，视觉参照真实绿牌「省·XXXXXXX」的 8 字符布局。

### 4.3 挡路抱歉区（Apology Hero）

- 全宽卡片，浅红渐变背景（`#FFF1F0 → #FFFFFF`），左缘红色竖条强调。
- 文案：主标题「挡路抱歉」，副文案「给您添麻烦了，点击下方按钮即可联系我挪车」。
- 大字号 + 高对比，保证「一眼看到」。

### 4.4 话术选择（Message Picker）

- 4 条常驻话术以 2×2 chips 网格呈现，单选。
  - 麻烦挪一下车
  - 挡住出入口了
  - 车灯没关
  - 我要出去了
- 选中态：红底白字 + 对勾；未选：白底灰边黑字。
- 下方「自定义文案」输入框，placeholder「或输入你想说的话…」；输入非空即覆盖 chips 选择，清空回落到 chip。

### 4.5 发送按钮（Primary CTA）

- 全宽、红色渐变、圆角、44px+ 高，文案「发送挪车提醒」。
- 状态：默认 → 点击 loading（转圈 + 禁点）→ 成功（短暂绿色「已发送，已电话加急车主」）→ 失败（红色可读原因）。

### 4.6 12123 底部弹窗（Bottom Sheet）

- 触发：点击「交警 12123 一键挪车」。
- 动画：`translateY(100%) → translateY(0)`，约 260ms `cubic-bezier(.4,0,.2,1)`；关闭反向。
- 结构：
  - 顶部拖拽把手（灰条）+ 标题「交管 12123 一键挪车」。
  - 步骤列表（1/2/3/4 带圆形序号）：打开 APP → 首页「一键挪车」→ 输入车牌 `鲁CDN0940` → 提交，系统以短信/电话通知车主。
  - 底部「我知道了」关闭按钮。
- 半透明遮罩点击关闭；滚动锁定防背景穿透。

### 4.7 买同款弹窗（Referral Modal）

- 触发：点击「买同款」。
- 居中弹窗（缩放淡入），展示小米汽车内推图片（`assets/referral.svg` 占位，待替换真实图）。
- 底部「长按保存 / 关闭」按钮。

## 6. 交互与动效

| 交互 | 动效 |
|------|------|
| chips 选择 | 150ms 背景/文字切换，加 ✓ |
| 发送 | 按钮 loading 转圈 → toast（顶部滑入，2.5s 自动消失） |
| 12123 弹窗 | 底部上滑 260ms + 遮罩淡入 |
| 买同款弹窗 | 居中缩放 + 遮罩淡入 |
| 关闭弹窗 | 反向动画后移除 |

## 7. 可访问性与细节

- 语义标签：`<button>` 承载所有可点击项，图标用 aria-label。
- 车牌/重点文案不依赖图片，可被读屏与复制。
- 对比度：正文 ≥ 4.5:1；绿牌黑字在绿色渐变上保持可读。
- 触控目标 ≥ 44×44px；弹窗滚动锁定。
